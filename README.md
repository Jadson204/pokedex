Pokédex é uma aplicação web interativa que permite explorar informações detalhadas sobre Pokémon, utilizando a PokéAPI como fonte de dados. Com um design inspirado na clássica Pokédex dos jogos, a aplicação oferece uma interface intuitiva e responsiva,
ideal para fãs da franquia que desejam buscar Pokémon por nome ou número, navegar pela lista sequencialmente ou até mesmo usar atalhos do teclado para uma experiência mais dinâmica. Desenvolvida com HTML, CSS e JavaScript, a Pokédex combina simplicidade
e funcionalidade, exibindo imagens animadas dos Pokémon, seus nomes e números de identificação de forma elegante e acessível.

## 🖥️ Como rodar o projeto 🖥️ ##

### Requisitos:

- Navegador web moderno (Chrome, Firefox, Edge, etc.)
- Conexão com a internet (para acessar a PokéAPI)

### Execução:

1. Clone o repositório:
   
   ```sh
   git clone https://github.com/Jadson204/pokedex.git
   ```

2. Acesse a pasta do projeto:
   
   ```sh
   cd pokedex
   ```

3. Abra o arquivo `index.html` diretamente em um navegador:
   - No Windows: clique duplo em index.html ou abra via navegador.
   - No macOS/Linux: use o comando open index.html ou arraste para o navegador.

    Alternativa: Use um servidor local para evitar problemas de CORS:

    ```sh
    npm install -g live-server
    live-server
    ```

4. Acesse a aplicação em `http://localhost:8080` (se usar live-server).

## 🗒️ Features do projeto 🗒️ ##
- Busca de Pokémon por nome ou número via campo de pesquisa.
- Navegação sequencial entre Pokémon usando botões "Anterior" e "Próximo".
- Suporte a navegação por setas do teclado (esquerda/direita).
- Exibição de imagens animadas dos Pokémon (sprites da geração V).
- Interface responsiva com design inspirado na Pokédex clássica.
- Feedback visual para Pokémon não encontrados.
- Carregamento inicial automático do Pokémon de ID 1 (Bulbasaur).
- Ícone de lupa interativo para realizar buscas.
